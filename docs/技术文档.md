# 割草幸存者 (Weed Survivor) — 技术文档

## 配置说明

### 开发环境搭建

#### 方式一：Arduino IDE（推荐）

1. **安装 Arduino IDE**：下载 [arduino.cc](https://www.arduino.cc/en/software)（2.x 版本）
2. **添加 Seeed Studio 板卡 URL**：
   - 文件 → 首选项 → 附加开发板管理器网址
   - 粘贴：`https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json`
3. **安装板卡包**：
   - 工具 → 开发板 → 开发板管理器
   - 搜索 `Seeed SAMD`，安装最新版
4. **选择开发板**：工具 → 开发板 → Seeed SAMD → Seeed Wio Terminal
5. **打开 sketch**：`sketch_aug8a.ino`
6. **编译上传**：点击 → （上传）

#### 方式二：命令行（arduino-cli）

```bash
# 安装 arduino-cli
curl -fsSL https://raw.githubusercontent.com/arduino/arduino-cli/master/install.sh | sh

# 添加板卡索引
arduino-cli config add board_manager.additional_urls \
  https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json

# 安装核心
arduino-cli core update-index
arduino-cli core install Seeeduino:samd

# 编译
arduino-cli compile --fqbn Seeeduino:samd:seeed_wio_terminal sketch_aug8a.ino

# 上传（需指定端口，如 /dev/ttyACM0 或 COM3）
arduino-cli upload -p /dev/ttyACM0 --fqbn Seeeduino:samd:seeed_wio_terminal sketch_aug8a.ino
```

#### 方式三：Web 烧录（无需安装任何软件）

*Web 烧录功能开发中，敬请期待。*

| 库名 | 版本要求 | 来源 | 备注 |
|------|---------|------|------|
| TFT_eSPI | 板核自带 | Seeeduino SAMD core | **禁止**从 Arduino 库管理器安装 Bodmer 版本 |

### 核心模块

#### 1. 渲染管线（双缓冲）

```
每帧流程：
gameSpr.fillScreen(0x0000)     ← 清空 sprite 缓冲区
drawBackground()                ← 画游戏区域背景
drawSlowZones()                 ← 画减速区域
drawGem() × N                   ← 画经验宝石
drawEnemy() × N                 ← 画敌人
drawBossAoE() × N               ← 画 BOSS 特效
drawProjectile() × N            ← 画投射物
drawScythe()                    ← 画镰刀轨道
drawAura()                      ← 画光环
drawPlayer()                    ← 画玩家
drawUI()                        ← 画 HP/XP/武器栏
gameSpr.pushSprite(0, 0)        ← 一次性推屏（零闪烁）
```

> **为什么用双缓冲**：320×240 的 ILI9341 刷新整屏约 30ms，如果逐元素推到物理屏会出现闪烁。先把所有元素画到 sprite，再一次性推屏，达到 30fps 稳定帧率。

#### 2. 武器系统

| 武器 ID | 名称 | 攻击方式 | 进化名称 | 进化条件 |
|---------|------|---------|---------|---------|
| 0 | 魔法草刃 | 向周围发射叶片弹幕 | 暴风草刃 | 满级 + 攻击力被动满级 |
| 1 | 旋风镰刀 | 环绕角色旋转切割 | 血镰 | 满级 + 移速被动满级 |
| 2 | 杂草光环 | 以角色为中心范围脉冲 | 毒光环 | 满级 + 护甲被动满级 |

**武器数据公式**：
```
冷却时间 = base_CD × 0.85^(level-1)       // 远程
伤害 = base_DMG × 1.2^(level-1)           // 伤害
叶片数 = 1 + (level-1)/2                  // 弹幕数量
进化加成 = 伤害×2.5, 范围×2, 冷却×0.7     // 全面强化
```

#### 3. 敌人系统

| 类型 | HP | 伤害 | 护甲 | 速度 | 经验 | 出现条件 |
|------|-----|------|------|------|------|------|
| 杂草 | 5 | 5 | 0% | 55 | 3 | 全程 |
| 蒲公英 | 9 | 7 | 0% | 40 | 5 | 游戏开始 2 分钟后 |
| 荆棘球 | 14 | 11 | 15% | 70 | 8 | 游戏开始 5 分钟后 |
| 精英草王 | 90 | 18 | 20% | 30 | 40 | 游戏开始 10 分钟后 / 定时生成 |
| BOSS 杂草之王 | 动态 | 300 | 40% | 8 | 0 | 50 级触发 |

> 所有敌人属性随游戏时间动态缩放（HP × 1.08^分钟，速度 × 1.03^分钟，伤害 × 1.05^分钟）

**敌人 AI**：
- 所有敌人向玩家位置移动（追踪 AI）
- 减速区域：速度 × 0.4
- 蒲公英：在移动路径上留下减速区域（速度 × 0.4），周期性生成
- BOSS：三种大招循环（毒雾圈 / 荆棘环 / 地刺爆发）

#### 4. 升级系统

**候选池优先级**：
```
进化（100） > 新武器（15） > 新被动（12） > 武器升级（10） > 被动升级（8） > 回复（5）
```

**流程**：
1. 收集所有可用选项（武器升级、新武器、被动升级、新被动、进化、回复）
2. 按优先级排序，取前 12 个
3. 随机选出 3 个不重复选项
4. 确保进化选项优先（替换最后一个）
5. 池为空时自动跳过升级面板

#### 5. 碰撞检测

- **投射物-敌人**：欧几里得距离 < 投射物半径 + 敌人半径
- **玩家-敌人**：距离 < 玩家半径 + 敌人半径，触发 hurtPlayer()
- **玩家-宝石**：距离 < 拾取范围，自动吸取
- 使用 `dist2()`（平方距离）避免开方运算，仅在需要精确距离时才用 `distF()`

#### 6. 随机数系统

自研 LCG（线性同余生成器），不依赖 `random()`：
```cpp
uint32_t rngState = 12345;
uint32_t rngNext() {
  rngState = rngState * 1103515245 + 12345;
  return rngState;
}
```
种子在每次重启时用 `micros()` 重置，保证每局随机性不同。

## 问题排查记录

### 问题 1：屏幕全黑（v0019-v0020）

**症状**：编译成功，烧录后屏幕不亮。

**根因**：`setup()` 中 `LCD_BACKLIGHT` 引脚（72）未初始化。

**修复**：
```cpp
pinMode(LCD_BACKLIGHT, OUTPUT);
digitalWrite(LCD_BACKLIGHT, HIGH);
```

**教训**：Wio Terminal 的 LCD 背光由独立 GPIO 控制，任何屏幕操作前必须拉高。

---

### 问题 2：升级选项面板空白（v0024）

**症状**：角色满级后，所有武器和被动都满级，升级面板弹出但无选项显示。

**根因**：`generateUpgrades()` 中 `poolSize==0` 时，`topN=0`，`rngInt(0, -1)` 返回 0，`selected[0]=0`，读取未初始化的 `pool[0]`。

**修复**：
```cpp
if (topN == 0) { upgradeOptionCount = 0; return; }
```
同时在 `addExp()` 中检查 `upgradeOptionCount==0`，跳过升级面板。

**教训**：随机数函数的边界检查必须覆盖空池情况。

---

### 问题 3：胜利/死亡画面与游戏画面重叠（v0025-v0028）

**症状**：通关或死亡后，游戏画面仍然可见，切换画面时有残留。

**演进过程**：

**v0025 尝试**：用 `static unsigned long vStart/gStart` 控制动画时间 —— 失败，因为 `static` 变量只在首次进入时初始化，重开游戏不重置。

**v0026 尝试**：改用全局 `screenEnterTime` + `lastScreen` 状态机 —— 部分解决，但画面仍有残留。

**v0028 根因**：胜利/死亡画面画到 `gameSpr`（双缓冲），`pushSprite` 推屏时与游戏画面的 `pushSprite` 冲突。

**v0028 修复**：将 `drawVictoryScreen()` 和 `drawGameOverScreen()` 改为直接画到 `tft`（物理屏），不走 `gameSpr` 双缓冲。

**v0030 最终修复**：重启时增加 `gameSpr.fillScreen(0x0000); gameSpr.pushSprite(0, 0);` 将物理屏强制清空。

**教训**：双缓冲和直接绘制不能混用。如果画面不需要双缓冲内容，直接画到物理屏更干净。

---

### 问题 4：按键检测抖动（v0020）

**症状**：按一次按钮触发多次升级选择。

**根因**：Arduino 循环速度（~30fps）远快于按键释放速度，`digitalRead(LOW)` 在多帧内持续为真。

**修复**：
```cpp
static bool upPrev = false, downPrev = false;
bool upNow = (digitalRead(WIO_5S_UP) == LOW);
if (upNow && !upPrev) { /* 触发一次 */ }
upPrev = upNow;
```

**教训**：所有按键检测必须使用上升沿/下降沿检测，而非电平检测。

---

### 问题 5：游戏重启后 `lastFrameTime` 跳跃（v0022）

**症状**：重新开始游戏后，第一帧 `dt` 极大（数秒），导致瞬间生成大量敌人。

**根因**：`lastFrameTime` 在重启时未重置，`dt = (now - lastFrameTime) / 1000` 等于暂停期间的时长。

**修复**：重启时 `lastFrameTime = millis();`。

**教训**：任何时间基准变量在状态重置时必须同步重置。

---

### 问题 6：`tone()` 阻塞（v0021）

**症状**：连续触发音效时，第二个音效不播放。

**根因**：`tone()` 在 Wio Terminal 上约需 20ms 执行，连续调用会覆盖。

**修复**：
```cpp
static unsigned long beepEndTime = 0;
void beep(int freq, int duration) {
  unsigned long now = millis();
  if (now < beepEndTime) return;  // 跳过重叠音效
  tone(WIO_BUZZER, freq, duration);
  beepEndTime = now + duration + 20;
}
```

**教训**：无源蜂鸣器的 `tone()` 是阻塞调用，需要防重叠机制。

---

### 问题 7：`drawBackground()` 抖动（v0025）

**症状**：游戏区域背景闪烁，草丛小点位置不固定。

**根因**：`drawBackground()` 每帧用 `rngNext()` 随机绘制 60 个草丛点，随机数种子在变化。

**状态**：已知问题，作为"动态草地"的设计特征保留。

## 性能优化记录

| 优化项 | 方法 | 效果 |
|--------|------|------|
| 碰撞检测 | 用 `dist2()` 替代 `distF()`，避免开方 | 帧率 +5fps |
| 投射物池 | 预分配数组，链表管理空闲槽位 | 避免动态分配 |
| 敌人排序 | 冒泡排序仅在前 12 候选中使用 | 池大小可控 |
| 双缓冲 | 全帧画到 sprite 再推屏 | 消除闪烁 |
| 帧率限制 | `dt > 0.1f` 时钳位到 0.1 | 防止大帧跳跃 |
| 精英计时器 | 用 `static` 变量 + `dt` 累加 | 避免 `millis()` 频繁调用 |

## 扩展指南

### 添加新武器

1. 在 `getWeaponStats()` 的 `switch` 中增加 `case 3:`
2. 定义冷却、伤害、额外参数（参照现有武器）
3. 在 `updateGame()` 中增加武器攻击逻辑
4. 在 `drawXxx()` 中增加渲染函数
5. 在 `generateUpgrades()` 的新武器循环中增加 `wid < 4`

### 添加新敌人

1. 在 `EnemyType` 枚举中增加新类型
2. 在 `spawnEnemy()` 的类型选择中增加概率分支
3. 在 `switch(e.type)` 中设置 HP、速度、伤害、经验值
4. 在 `drawEnemy()` 中增加绘制分支

### 添加新被动

1. 在 `getPassivePerLevel()` 中增加效果值
2. 在 `recalcStats()` 中增加属性计算
3. 在 `passiveNames[]` 中增加名称
4. 在 `generateUpgrades()` 的新被动循环中增加 `pid < 6`

### 添加排行榜（microSD）

1. 使用 `SPI2` 接口读写 microSD
2. 在游戏结束时写入分数
3. 在标题画面读取并显示排行榜

### 添加 WiFi 排行榜

1. 使用 `Seeed Arduino rpcWiFi` 库连接 WiFi
2. 使用 HTTP POST 上传分数到服务器
3. 使用 HTTP GET 获取排行榜数据
