## 拍摄建议

- **设备**：Wio Terminal 实机 + 三脚架固定手机/相机拍摄
- **光线**：避免屏幕反光，侧光补光
- **音效**：蜂鸣器声音偏小，建议后期叠加或用外接麦克风近距离收音
- **关键画面**：BOSS 战、武器进化、升级面板，给特写
- **后期**：叠加文字标注（武器名、伤害数字、HP 条变化）
