# 割草幸存者 (Weed Survivor) — 背景信息概况

## 一句话概括

> 一款运行在 Wio Terminal 嵌入式开发板上的吸血鬼幸存者风格割草游戏，320×240 像素，< 100KB 固件，满屏 120 只怪物流畅运行。

---

## 解决什么问题

### 1. 嵌入式设备的"游戏荒漠"
大多数嵌入式项目停留在"传感器读数 + 屏幕显示"的 demo 阶段，缺乏完整的交互闭环。Weed Survivor 证明：**192KB RAM 的 Cortex-M4F 芯片也能跑出完整的手游级体验**——从开始画面到通关/Victory 画面，从升级树到 BOSS 战，从音效到屏幕震动，全链路闭环。

### 2. 创客教育的"动机缺失"
传统的 Arduino 教学案例（闪烁 LED、读取温度）对青少年吸引力有限。一款**游戏**天然具备"做出来想玩、玩完想改"的驱动力，涵盖数据结构、算法、渲染、物理、UI 设计等知识点，让学习变成"改游戏参数 / 加新武器 / 画新敌人"。

### 3. 低功耗设备的"性能天花板"探索
Wio Terminal 的 SAMD51 处理器（120MHz Cortex-M4F）在嵌入式领域算中上水平，但跑 120 只怪物 + 30 个投射物 + 粒子特效，需要精细的帧率管理。本项目探索了**内存布局、碰撞检测优化、精灵渲染管线**在受限硬件上的极限。

## 为谁设计

| 用户群体 | 需求 | 本项目满足 |
|----------|------|-----------|
| **创客 / 硬件爱好者** | 想做一个"酷"的项目，而不是又一个温度计 | 完整的游戏，展示即拿得出手 |
| **STEM 教育者** | 需要能吸引学生的教学案例 | 涵盖数据结构、状态机、碰撞检测、双缓冲渲染 |
| **嵌入式开发者** | 想了解 TFT_eSPI 双缓冲、Sprite 渲染、内存优化 | 代码注释详尽，架构清晰，可直接参考 |
| **游戏爱好者** | 想在掌机上玩割草游戏 | 5 分钟一局，通勤/排队碎片时间 |
| **学生 / 参赛者** | 需要创客比赛/毕业设计作品 | 完整项目包（文档+代码+固件），可直接演示 |

## 市场价值

### 1. 教育市场
- **Arduino 官方课程**：可集成到 Arduino 进阶课程中，替代枯燥的 LED 实验
- **创客训练营**：Seeed Studio 的 Wio Terminal 课程目前缺乏游戏类案例，本项目可填补空白
- **大学嵌入式课程**：作为期末大作业/课程设计模板

### 2. 开源社区
- **GitHub 开源**：吸引嵌入式 + 游戏开发交叉领域的关注
- **Hackaday / Instructables**：发布制作教程，获得社区曝光
- **Wio Terminal 生态**：丰富 Wio Terminal 的应用场景，推动硬件销量

### 3. 商业衍生
- **掌机移植**：可编译到 ESP32 系列（XIAO ESP32S3、M5Stack），支持更多硬件平台
- **硬件套装**："Wio Terminal + 游戏固件 + 3D 打印外壳" 作为入门套件销售
- **IP 授权**：游戏机制可授权给其他嵌入式平台

### 4. 技术演示价值
- 证明 Wio Terminal **不只是传感器读取板**，能做复杂交互应用
- 作为 Seeed Studio 官方 Demo，展示 SAMD51 的性能上限
- 吸引更多开发者关注 Wio Terminal 生态

| 维度 | 吸血鬼幸存者 (PC/手机) | 同类嵌入式游戏 | 本项目 |

| 音效 | 完整 OST | 蜂鸣器单音 | PWM 多频率音效引擎 |

| 开发难度 | 团队级 | 个人 | 个人（约 1400 行 C++，17 个文件） |
